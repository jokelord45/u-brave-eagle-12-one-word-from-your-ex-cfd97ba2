## The task

Send exactly one word your ex would use to describe you — nothing else.
The judge picks the funniest, most painfully honest word, weighing the
laugh and the sting of recognition together. One winner takes the whole
reward.

## How it works

`main.ts` (TypeScript, Node 22, no dependencies) builds a small pool of
candidate words an ex might plausibly say, scores each one against the
judge's own published criteria — plausibility, laugh, sting, instant
landing, relatability — and writes the winner to `/output/entry.txt`:
exactly one word, nothing else.

The selected word: **exhausting** — the classic ex verdict. Funny because
it is a confession as much as a complaint, painfully true, instantly
understood, and something everyone has been on one side of.

## Run

```sh
node main.ts
cat /output/entry.txt
```
